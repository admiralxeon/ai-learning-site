Instructor kit

This kit helps teachers and trainers to use the manual in a class, a company training, or a study group. It has a lesson plan of 90 minutes and a set of slides for each module. The plans and the slides are made from the modules, so they always agree with the content.

1

Course formats

FormatPlanGood for
AI Foundations, 6 weeksOne 90-minute class each week for Modules 1 to 6, and the final review in week 6.Schools, colleges, and all staff of a company.
AI Engineer, 12 weeksOne class each week with the weekly plan, a lab session for the projects, and the capstone in weeks 9 to 12.Engineering students, developers, and data teams.
Workshop, 2 daysDay 1: Modules 1, 3, and 5 with their playgrounds. Day 2: Module 6, Project 6, and a short capstone plan.Managers and teams who need a fast start.
2

How to teach with the manual

  • Flip the class. Learners read the module before the class. Use the class time for the playgrounds, the discussions, and the exercises.
  • Use the simple language. The text is written in Simplified Technical English, so it is easier for people who learn in a second language. Use the same short sentences when you speak.
  • Use the story. The mango checker connects the modules. Start each class with the problem of the farm in the current part of the story.
  • Let learners make errors. In the exercises, a failed test is a good start for a discussion.
  • Check accessibility. All pages work with a keyboard and a screen reader, and they have a display menu for larger text and a dark theme.
3

Assessment

  • Knowledge checks at the end of each module (pass mark 70%), and the final review (20 mixed questions, pass mark 75%).
  • Code exercises in each module, checked automatically in the browser.
  • Projects and the capstone, graded with the seven-part rubric. Grade a sample yourself, and compare it with the learner's self-assessment.
  • Verified certificates: sign the requests of learners who passed with tools/sign_certificate.py. Refer to the verify page and to the README of the repository.
4

Lesson plans and slides

Each plan is for one class of 90 minutes. Change the times to agree with your group. In the slides, use the arrow keys to move, N to show the speaker notes, and F for full screen. To print the slides or save them as a PDF, use the print command of the browser.

Module 0: Python and data tools

Open the module Open the slides About 11 min to read, 85 min of video

Learning outcomes

  • Run Python in Google Colab and on your own computer.
  • Write code with lists, dictionaries, loops, conditions, and functions.
  • Load, clean, filter, and summarize a table of data with pandas.
  • Get data from a database with SQL.
  • Use the terminal, a virtual environment, and Git.

Before the class

  • Try each playground yourself.
  • Watch or select the videos:

  • pandas tutorial, part 1: getting started (Corey Schafer)
  • SQL explained in 100 seconds (Fireship)
