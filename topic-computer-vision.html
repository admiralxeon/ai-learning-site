Computer vision: more than classification

This short topic is written in ASD-STE100 Simplified Technical English. Read Module 4, Deep learning first. Module 4 tells you how a CNN finds patterns in an image and gives one label for the full image. This topic tells you how a computer finds where each object is, which pixels belong to it, and how it reads text in images.

1

Scope

Computer vision is the part of AI that gets information from images and video. This topic gives a description of the four most usual tasks, how object detection works, where people use computer vision, and its limits.

2

Four tasks

The same photograph can give very different types of answer. Refer to Figure 1.

TaskOutputExample question
ClassificationOne label (and a probability) for the full image.Is this mango damaged?
Object detectionA box, a label, and a confidence for each object.How many mangoes are on this tree?
SegmentationA label for each pixel.How much of the leaf has the disease?
OCR (text recognition)The text in the image.What is written on the box?

A fifth task finds key points, for example the elbows, knees, and shoulders of a person. Fitness apps and sports analysis use key points to measure the movements of the body.

3

How object detection works

A detection model is usually a CNN or a vision transformer. Refer to Module 4, Section 6. For each part of the image, it predicts:

  • The four numbers of a bounding box: the position and the size of a rectangle.
  • A probability for each category, for example mango, leaf, or nothing.

The model finds many boxes that are almost the same for one mango. A step with the name non-maximum suppression keeps the box with the highest confidence and removes the other boxes that overlap it.

Is a box correct?

To measure a detection model, compare each predicted box with the correct box. IoU (intersection over union) measures how well two boxes overlap. Refer to Figure 2.

Example: each box has an area of 100 cm² on the screen, and the overlap is 60 cm². The two boxes together cover 100 + 100 − 60 = 140 cm². IoU = 60 ÷ 140 = 0.43. This is less than 0.5, thus the detection is not correct.

When you know which detections are correct, you can calculate precision and recall, as in Module 3, Section 10.

4

Segmentation and video

  • Semantic segmentation gives each pixel a category, for example "mango" or "leaf". Two mangoes that touch become one area.
  • Instance segmentation also separates the objects: "mango 1" and "mango 2". Figure 1C shows this.
  • Tracking connects the detections in each frame of a video, so that the system knows that it is the same mango or the same car.

Most teams do not train a vision model from zero. They start with a model that is already trained on millions of images and train it a little more on their own images. This is transfer learning. Refer to Module 4, Section 9. New multimodal models can also describe an image in words and answer questions about it. Refer to Module 5, Section 3.

Note

Labels for detection and segmentation take much more work than one label for each image. A person must draw each box or each object outline. Plan time and money for this work.

5

Where people use computer vision

AreaTaskExample
AgricultureDetection, segmentationCount fruit on trees. Find diseased leaves. Measure the size of fruit on a sorting line.
MedicineSegmentation, classificationMark possible tumors on scans, for a doctor to check.
FactoriesDetection, classificationFind scratches and defects on parts.
TransportDetection, trackingDriver assistance finds people, cars, and road signs. Read number plates.
Shops and storesDetectionFind empty shelves. Count stock in a store room.
OfficesOCRRead invoices, forms, and identity documents.
PhonesClassification, key pointsUnlock the phone with a face. Find photographs by their content.
6

Limits and risks

  • New conditions. A new camera, different light, rain, or a new type of object can decrease the accuracy. This is data drift. Refer to Module 7, Section 7.
  • Small and hidden objects. Objects that are small, far away, or partly hidden are difficult to find.
  • Attacks. A special printed pattern can make a model see something that is not there, or not see something that is there.
  • Bias. A face model that is trained mostly on one group of people can make more errors for other groups. Refer to Module 6, Section 3.
Warning

A photograph of a face is personal data. Face recognition in public places has strict rules in many countries, for example in the EU AI Act. Refer to Module 6, Section 4. Do not use face recognition without a legal check.

7

Summary

  • Classification says what is in an image. Detection, segmentation, and OCR also say where.
  • A detection model predicts a box, a label, and a confidence for each object.
  • IoU measures how well a predicted box matches the correct box. 0.5 or more is a usual limit.
  • Instance segmentation separates the objects. Tracking follows them through a video.
  • Use transfer learning, and plan for the work of drawing the labels.
  • Monitor for new conditions, and take special care with faces.

9

Technical names

Bounding box
A rectangle around an object. Four numbers give its position and size.
Computer vision
The part of AI that gets information from images and video.
IoU
Intersection over union: the overlap area of two boxes divided by the area of both boxes together.
Key point
An important point on an object, for example a knee or an elbow of a person.
Non-maximum suppression
A step that keeps the box with the highest confidence and removes the other boxes that overlap it.
Object detection
A task that finds each object in an image and gives a box and a label for each one.
OCR
Optical character recognition: a task that changes text in an image into text that a computer can use.
Segmentation
A task that gives a label to each pixel of an image.
Vision transformer
A transformer that divides an image into small squares and uses attention between them.
