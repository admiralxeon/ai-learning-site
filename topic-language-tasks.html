Language tasks: what AI does with text

This short topic is written in ASD-STE100 Simplified Technical English. Read Module 4, Deep learning and Module 5, Generative AI first. A chat AI is only one use of language AI. This topic tells you about the other usual tasks, how they work, and when a small special model is better than a large language model.

1

Scope

Natural language processing (NLP) is the part of AI that works with human language. This topic gives a description of the types of language task, how a computer finds names in text, how search by meaning works, and how to select a model.

2

Types of language task

Most language tasks have one of four shapes. The shape is the type of output. Refer to Figure 1.

ShapeTasks
1. One labelSentiment analysis, spam filters, sorting of support emails by subject, detection of harmful text.
2. A label for each wordNamed entity recognition (NER), the parts of speech of each word.
3. New textMachine translation, summaries, correction of grammar, text from speech.
4. An answerQuestions and answers with RAG. Refer to Module 5, Section 8.
3

How a computer finds names in text

NER is a classification for each token, not for the full text. The model reads all the text with attention, so it knows the context of each word. Then it gives each token a label. Refer to Module 4, Section 8.

The context is important. In "Pune is the city where I live", Pune is a place. In "The Pune team won", Pune is part of the name of an organization. A model that only looks at one word at a time cannot see this difference.

Companies use NER to get data from documents automatically: the names, the dates, and the amounts in invoices, contracts, or medical notes.

4

Search by meaning

A usual search finds documents that contain the same words as the question. Semantic search finds documents with the same meaning, also when the words are different.

  1. A model changes each document into an embedding: a list of numbers that keeps its meaning. Refer to Module 4, Section 7.
  2. The model changes the question into an embedding in the same way.
  3. The system calculates the cosine similarity between the question and each document. Refer to Module 2, Section 9.
  4. The system shows the documents with the highest similarity first.
Question: "My mango has black spots"Same words?Similarity (example)
"Anthracnose: a fungus disease that makes dark marks on the fruit skin"No0.82
"How to keep mangoes fresh at home"Yes: "mango"0.41
"Prices of black pepper this week"Yes: "black"0.12

The best answer does not contain any word of the question. A word search would show it last. RAG uses semantic search to find the parts of documents that go into the prompt.

Speech

Speech recognition changes speech into text. Then the system can use all the text tasks on it. Voice assistants do this: speech to text, then a language task, then text to speech for the answer.

5

A small model or a large language model?

You can do most text tasks in two ways. Refer to the table.

PointSmall special modelLarge language model with a prompt
TrainingYou fine-tune it with hundreds or thousands of labeled examples.No training. You write a prompt with some examples.
Speed and costVery fast and cheap. It can run on your own computer.Slower. You usually pay for each token.
FlexibilityIt does one task only.It can do many tasks, and new tasks immediately.
OutputAlways in the same format.Can change. Needs output checks.
Good forMillions of texts each day, with a fixed task.A new task, few examples, or a task that changes.
Note

A usual plan: start with an LLM and a prompt, to test the idea quickly. Use its answers, checked by people, as labels. If the volume becomes large, train a small model with these labels. Always compare the two with the same evaluation set. Refer to Module 7, Section 8.

6

Where people use language AI

AreaExample
Customer supportSort incoming messages by subject and urgency. Suggest answers to the support team.
BusinessFind the opinions in thousands of product reviews. Get data from invoices and contracts.
Government and healthTranslate public information into many languages. Make notes from a doctor's conversation, for the doctor to check.
SearchSearch by meaning in company documents, help pages, and laws.
AccessibilitySubtitles for videos, voice control for people who cannot use a keyboard.
7

Limits and risks

  • Languages with less data. Models are usually best in English. Many Indian languages have less training text, so the results can be worse. Text that mixes languages, for example Hindi and English in one sentence, is also more difficult. Test with your own users' language.
  • False content. A summary or a translation can add, remove, or change facts. Check important texts.
  • Bias. A sentiment model can give lower scores to some dialects or names. Measure the results for each group. Refer to Module 6, Section 3.
  • Private data. Emails, chats, and medical notes contain personal data. Remove it or get permission before you use it.
8

Summary

  • Language tasks give one label, a label for each word, new text, or an answer from documents.
  • NER gives each token a label. It needs the context of the full sentence.
  • Semantic search compares embeddings. It finds the same meaning with different words.
  • A small special model is fast and cheap for one fixed task. An LLM is flexible and needs no training.
  • Test with the languages of your users, and check important outputs.

10

Technical names

Machine translation
A task that changes text from one language into another language.
Named entity recognition
A task that finds names of people, places, organizations, dates, and amounts in text.
Natural language processing
The part of AI that works with human language: text and speech.
Semantic search
A search that compares the meaning of the question and the documents with embeddings.
Sentiment analysis
A task that finds if a text is positive, negative, or neutral.
Speech recognition
A task that changes spoken words into text.
