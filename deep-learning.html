Deep learning: general description

This module is written in ASD-STE100 Simplified Technical English, at approximately 80% compliance. Read Module 1, Artificial intelligence and Module 3, Machine learning before you read this module. Names with a dotted line are technical names. Put the pointer on a name to see its definition.

1

Scope

This module gives a description of deep learning.

It tells you:

  • What deep learning is, and how it is different from classic machine learning.
  • How one neuron calculates its output.
  • How a deep network learns with backpropagation.
  • The main types of neural network.
  • How a network finds patterns in images.
  • How a network changes words into numbers.
  • How a transformer uses attention.
  • How to train a deep network in practice.
2

What deep learning is

Deep learning is a part of machine learning. It uses neural networks with many layers. The word "deep" refers to the number of layers. A deep network can have from ten to more than one hundred layers.

In classic machine learning, a person usually selects the features. For example, to identify a cat, a person can tell the model to measure the shape of the ears. In deep learning, the network finds the useful features in the raw data. Refer to Figure 1.

Deep learning is the best method for data that does not have a clear structure, for example images, sound, and text.

ItemClassic machine learningDeep learning
FeaturesA person selects them.The network finds them.
Quantity of dataHundreds to thousands of examples.Thousands to billions of examples.
Computer powerA usual computer.Special chips (GPUs). Refer to Section 9.
Explanation of resultsUsually easy.Difficult.
Best forTables of numbers.Images, sound, and text.
Note

For data in tables, classic methods are frequently as accurate as deep learning. They are also faster and easier to explain. Refer to Module 3, Section 11.

3

Inside a neuron

Module 1 tells you that a neural network has neurons in layers. Each neuron does a small calculation. Refer to Figure 2.

  1. The neuron receives numbers from the previous layer.
  2. It multiplies each number by its weight.
  3. It adds all the results.
  4. It adds one more number. We call this number the bias.
  5. It applies an activation function to the total.
  6. It sends the result to the neurons in the next layer.

The most common activation function is ReLU. ReLU changes negative numbers to zero. It does not change positive numbers.

Try it

Change the weights of a neuron

This is the neuron from Figure 2. Move the weights and the bias. Look at the total and at the output after ReLU. Then try the challenges.

Note

Without an activation function, many layers act the same as one layer. The activation function lets the network learn complex patterns, for example curves, and not only straight lines.

4

How a deep network learns

A deep network learns with gradient descent. Refer to Module 3, Section 8. But a deep network has millions or billions of weights. The system must find the gradient for each weight. A method with the name backpropagation does this quickly. Refer to Figure 3.

  1. The data goes through the layers, from the input to the output. The network makes a prediction. We call this the forward pass.
  2. The system compares the prediction with the label. It calculates the loss.
  3. The system goes back through the layers, from the output to the input. It calculates how much each weight caused the error. We call this the backward pass.
  4. The system changes each weight by a small quantity, in the direction that decreases the loss.
  5. The system does these steps again with the next group of examples.

The system does not use all the training data at one time. It uses small groups of examples. We call each group a batch. One pass through all of the training data is an epoch. Training usually needs many epochs.

There are different designs of neural network. Each design is good for a different type of data.

6

How a network finds patterns in images

A photograph has millions of pixels. A usual network would need too many weights. A convolutional neural network (CNN) solves this problem.

A CNN uses small filters. A filter is a small grid of weights, for example 3 × 3. The filter moves across the image, one position at a time. At each position, it calculates one number. The result is a new grid that we call a feature map. The feature map shows where the filter found its pattern. Refer to Figure 4.

The same filter is used at all positions. Thus a CNN needs fewer weights. It can also find a pattern in any part of the image.

A CNN has many layers of filters:

  • The first layers find edges and lines.
  • The middle layers find shapes, for example circles and corners.
  • The last layers find parts of objects, for example eyes or wheels.
  • The output layer gives the result, for example "cat: 92%".

Training finds the values in the filters. A person does not design them.

How a network changes words into numbers

A neural network can use only numbers. Thus the system must change words, images, and other items into numbers. An embedding is a list of numbers that shows the meaning of an item. We call a list of numbers a vector.

The network learns the embeddings during training. Items with similar meanings get similar numbers. Thus their embeddings are near each other. Refer to Figure 5.

Systems use embeddings to:

  • Find text with the same meaning, not only the same words. Refer to Module 5, Section 8.
  • Recommend similar products, films, or songs.
  • Put similar documents into groups.
  • Start the calculation in a transformer. Refer to Section 8.
8

How a transformer uses attention

Module 1 tells you that most LLMs use a transformer. This section tells you how a transformer works.

The meaning of a word depends on the other words in the text. Look at the sentence "The animal did not cross the street because it was tired". Here, the word "it" refers to the animal. In "... because it was too wide", the word "it" refers to the street.

A method with the name attention solves this problem. For each token, attention calculates how important each other token is. Then it adds information from the important tokens into this token. Refer to Figure 6.

The steps in a transformer

  1. The system cuts the text into tokens.
  2. The system changes each token into an embedding. It also adds information about the position of each token.
  3. In an attention layer, each token collects information from the other tokens.
  4. In a feedforward layer, each token goes through a small neural network.
  5. The model does steps 3 and 4 again in many layers. A large model can have more than 100 layers.
  6. The last layer gives the probability of each possible next token. Refer to Module 1, Section 6.

A transformer does the calculations for all tokens at the same time. Thus it can use the power of GPUs well. This is one reason why transformers replaced the older designs.

9

Deep learning in practice

Computer power

Deep learning needs very many calculations. A GPU is a computer chip that does many calculations at the same time. Small networks can train on one GPU. Large language models train on thousands of GPUs for weeks or months.

Prevent overfitting

A deep network has very many weights. Thus it can easily remember the training data. Refer to Module 3, Section 9. Use these methods to prevent overfitting:

  • Dropout. During training, the system switches off some random neurons. Thus the network cannot depend on a small number of neurons.
  • Data augmentation. The system makes more training examples from the existing examples. For example, it turns, flips, or crops each image.
  • Early stopping. The system stops training when the validation loss starts to increase.

Transfer learning

To train a large network from zero, you need very much data and money. Transfer learning is a different method:

  1. Start with a network that is already trained on a large data set. For example, a network that is trained on millions of photographs.
  2. Train it a little more on your small data set. For example, 500 photographs of defects on your parts.

The network keeps its general knowledge, for example how to find edges and shapes. It only learns the new task. Generative AI uses the same principle. Refer to Module 5, Section 4.

A better model for photographs

The model from Part 3 is a classic ML model. A person selected its features, for example the average color. It cannot see small spots well.

The team changes to a CNN. They use transfer learning:

  1. Start with a CNN that is trained on millions of general photographs.
  2. Train it more on the 6,000 mango photographs.
  3. Use data augmentation: turn and flip the photographs, and change their brightness.

The new model finds small spots and works in different light. The recall for damaged mangoes is now 97%.

A buyer asks: "Why did the model put this mango in the damaged box?" The team cannot easily answer. Thus a worker does a check of each mango in the damaged box.

Think: why does data augmentation with changes of brightness help this model?

The light on the farm is different in the morning and in the evening. When the model sees training photographs with many types of light, it learns to ignore the light and to look at the mango.

Warning

It is difficult to know why a deep network gives an answer. Do not use a deep network alone for decisions that have a large effect on people, for example a loan or a medical diagnosis. A qualified person must do a check of the decision.

10

Summary

  • Deep learning uses neural networks with many layers. The network finds the features in the raw data.
  • Each neuron multiplies its inputs by weights, adds a bias, and applies an activation function.
  • Backpropagation finds the gradient for each weight. Gradient descent then adjusts the weights.
  • CNNs use filters to find patterns in images.
  • Embeddings change items into lists of numbers. Similar items have similar embeddings.
  • Transformers use attention to connect each token to the other tokens.
  • Transfer learning gives good results with less data.

Technical names

These names are not in the STE dictionary. STE lets you use technical names that are necessary for the subject.

Activation function
A simple function that a neuron applies to its total.
Attention
A method that lets each token collect information from the other tokens.
Backpropagation
A method that calculates the gradient for each weight, from the output back to the input.
Batch
A small group of training examples for one update of the weights.
Bias
A number that a neuron adds to its total.
CNN
Convolutional neural network. It uses filters to find patterns in images.
Data augmentation
A method that makes more training examples from the existing examples.
Deep learning
Machine learning that uses neural networks with many layers.
Dropout
A method that switches off random neurons during training.
Embedding
A list of numbers that shows the meaning of an item.
Epoch
One complete pass through all of the training data.
Feature map
The grid of numbers that a filter makes.
Filter
A small grid of weights that finds one type of pattern in an image.
Forward pass
The calculation from the input layer to the output layer.
GPU
Graphics processing unit. A chip that does many calculations at the same time.
ReLU
An activation function that changes negative numbers to zero.
RNN
Recurrent neural network. It reads a sequence one item at a time.
Transfer learning
Training that starts from a model that is already trained.
Transformer
A network design that uses attention.
Vector
An ordered list of numbers.
