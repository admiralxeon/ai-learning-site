What machine learning is

Machine learning is one part of AI. In ML, a computer learns from examples. A person does not write the rules. The computer finds the rules in the data.

Notes: Think of a person who learns to identify ripe mangoes. Nobody gives that person a list of rules. The person looks at many mangoes. Each time, somebody tells the person "ripe" or "not ripe". After many examples, the person can identify a ripe mango alone. ML uses the same principle. Open the section

Data

ML data is usually a table. Each row is one example. Each column gives one item of information about the example. We call these columns features. The value that the model must predict is the label. Refer to Figure 2.

Notes: Bad data makes a bad model. If the data has errors, gaps, or bias, the model learns them. Always do a check of the data before training. Before training, divide the data into three sets. Refer to Figure 3. Do not let the model see the test set during training. If it sees the test set, the test result will be too good. It will not show the real accuracy. Open the section

Unsupervised learning

In unsupervised learning, the examples do not have labels. The model finds patterns alone. A usual task is clustering. The model puts similar examples into groups. Refer to Figure 5.

Notes: Example: a shop has data about its customers. Nobody knows the types of customer. The model finds three groups: students, families, and office workers. Then the shop can send different offers to each group. Open the section

How a model makes its errors smaller

During training, the system measures the errors of the model. The result is one number. We call this number the loss. A high loss shows many errors. A low loss shows few errors. The objective of training is to make the loss as low as possible.

Notes: Most models use a method with the name gradient descent . Think of a person on a hill in fog. The person cannot see the bottom. But the person can feel the slope under the feet. The person takes a step downhill. Then the person feels the slope again and takes the next step. Gradient descent does the same thing with the loss. Refer to Figure 7. The size of each step is the learning rate . Neural networks also use gradient descent. They use a method with the name backpropagation to calculate the gradient. Refer to Module 4, Section 4 . How to measure a model

After training, measure the model with the test set. For a classification model, use a confusion matrix. It compares the predictions with the correct answers. Refer to Figure 9.

Notes: High accuracy is not always good. Think of a disease that occurs in 1 of 100 persons. A model that always says "no disease" is 99% accurate. But it finds zero sick persons. Thus, also look at precision and recall. Open the section

Summary

  • In ML, the computer finds the rules in data.
  • The ML workflow has eight steps, from the problem definition to monitoring.
  • Features are the inputs. The label is the correct answer.
  • Divide the data into training, validation, and test sets.
  • Supervised learning uses labels. Unsupervised learning finds groups. Reinforcement learning uses rewards.
  • Gradient descent makes the loss smaller, step by step.
