What generative AI is

Most models in Module 3 are predictive. A predictive model looks at an input. Then it gives a label or a number. For example, it tells you if an email is spam.

Notes: Generative AI is different. It makes new content. This content did not exist before. The model learns the patterns in its training data. Then it uses these patterns to make new examples that are similar to the data. Refer to Figure 1. A large generative model can do many different tasks. We call this type of model a foundation model . Companies use one foundation model in many products, for example chat, writing help, code help, and search. Generative AI does not copy text or pictures from a database. It makes new output from the patterns that it learned. But sometimes the output can be very similar to an item in the training data. Open the section

Types of generative AI

Generative models can make different types of content. We call each type of content a modality.

Notes: A multimodal model can use more than one modality. For example, it can receive a photograph and a question. Then it writes an answer about the photograph. Open the section

How a large language model is made

A modern chat AI is made in three stages. Refer to Figure 2.

Notes: In pretraining , the model reads a very large quantity of text. Its task is to predict the next token. For more information about tokens, refer to Module 1, Section 6 . Most of these models are transformers. Refer to Module 4, Section 8 . Pretraining can take months. It uses thousands of special computer chips at the same time. We call these chips GPUs . Pretraining is the most expensive stage. The result is a base model . A base model knows much about language and about the world. But it only continues text. If you ask it a question, it can write more questions in place of an answer. Open the section

How a model selects its output

Module 1 tells you that a model calculates a probability for each possible next token. Then the system selects one token. We call this selection sampling.

Notes: If the system always selects the token with the highest probability, the text is predictable. But the text can become repetitive. If the system sometimes selects a token with a lower probability, the text is more varied. A setting with the name temperature controls this. Refer to Figure 3. Because of sampling, the same prompt can give a different answer each time. This is usual. It is not a fault. Open the section

Connect a model to documents and tools

A model knows only its training data. It does not know your company documents or the news of today. A method with the name RAG solves this problem. Refer to Figure 6.

Risks of generative AI

Generative AI can make content that looks real but is false. This includes text, photographs, voices, and videos. Do not believe content only because it looks real.

  • Hallucinations. A model can invent facts, quotes, and references. The text can sound correct and confident. Refer to Module 1, Section 8.
  • Deepfakes. A deepfake is a false image, video, or voice of a real person. Criminals use deepfakes for fraud. For example, a false voice of a family member asks for money.
  • Copyright. Models are trained on content that people made. The rules about the use of this content are different in different countries. The output can also be similar to an existing work.
  • Bias. Text and images from a model can repeat unfair ideas from the training data.
  • Prompt injection. A web page or a document can contain hidden instructions for an AI. We call this prompt injection. These instructions can make an AI agent do something that you did not ask for.
  • Private data. Data that you give to an AI tool can be kept by the company that makes the tool.
Notes: Know these risks: Obey the rules of your school or company for the use of AI. Some rules tell you to say when AI helped you to make a document. Open the section

Summary

  • Generative AI makes new content: text, images, sound, video, and code.
  • A chat AI is made in three stages: pretraining, fine-tuning, and human feedback.
  • Temperature controls how predictable or varied the output is.
  • The context window limits how much text a model can use at one time.
  • An image generator starts from noise and removes it step by step.
  • A good prompt gives the task, the context, the format, and an example.
