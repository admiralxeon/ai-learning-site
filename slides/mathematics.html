Why AI needs mathematics

A model is a mathematical function. It changes input numbers into output numbers. Training changes the numbers inside the function until the output is good. Four parts of mathematics do this work:

Variables and functions

A variable is a name for a value that can change. Mathematics usually uses letters, for example x or w.

Notes: A function is a rule that changes each input into one output. Refer to Figure 1. In the function f ( x ) = 2 x + 1, the numbers 2 and 1 are parameters . A model is a function with many parameters. In a neural network, the parameters are the weights and the biases. Training finds good values for them. Machine learning frequently adds many values. The symbol Σ (the Greek letter sigma) means "add all of these". Open the section

Statistics: describe data

Before you train a model, you must know your data. Statistics gives a few numbers that describe many values. In this section, the data is the weight of seven mangoes from Asha's farm, in grams:

  • The mean (average) is the sum of the values, divided by the number of values: 2,095 ÷ 7 ≈ 299 g.
  • The median is the middle value when the values are in order: 300 g.
  • The mode is the value that occurs most frequently. Here, each value occurs one time, so there is no mode.
Notes: An outlier is a value that is very different from the others. One outlier can change the mean very much. If a worker types 2,000 g in place of 315 g, the mean becomes 540 g. The median stays at 300 g. Always look for outliers before you train a model. Open the section

Distributions

A distribution shows how frequently each value occurs. Many measurements in nature have a normal distribution. Its shape is like a bell. Most values are near the mean. Few values are far from the mean. Refer to Figure 2.

Notes: In a normal distribution: Features can have very different sizes. For example, the weight of a mango is approximately 300, but its ripeness score is between 0 and 1. Many models learn better when all features have a similar size. Standardization changes each value into a z-score: Example: a mango of 322 g has z = (322 − 300) ÷ 11 = 2. It is 2 standard deviations heavier than the mean. This is unusual, but not an error. Open the section

Correlation

Correlation shows how strongly two values change together. The correlation coefficient r is between −1 and +1. Refer to Figure 3.

Notes: Correlation does not show cause. In summer, people buy more ice cream, and more people swim and have accidents in the water. The two values have a strong correlation, but ice cream does not cause the accidents. The hot weather causes both. A model learns correlations. It does not know causes. Open the section

Probability

A probability is a number between 0 and 1. It shows how possible an event is. 0 means "impossible". 1 means "certain". We write P(A) for "the probability of A".

  • A usual die has 6 sides. P(you throw a 6) = 1 ÷ 6 ≈ 0.17.
  • The probability that A does not occur is 1 − P(A). P(no 6) = 1 − 0.17 = 0.83.
  • If two events do not have an effect on each other, they are independent. The probability that both occur is P(A) × P(B). Two coins both show heads: 0.5 × 0.5 = 0.25.
Notes: A conditional probability is the probability of A when you know that B occurred. We write P(A | B), and we say "the probability of A, given B". Bayes' rule changes a probability when you get new information: Example: 3% of Asha's mangoes are damaged. The checker finds 90% of the damaged mangoes. But it also puts 5% of the good mangoes into the damaged box. If a mango is in the damaged box, what is the probability that it is really damaged? Think of 1,000 mangoes: Open the section

Probability in AI models

A classification model first calculates a score for each category. A function with the name softmax changes the scores into probabilities:

  1. Calculate escore for each score. The number e is approximately 2.718.
  2. Add all the results.
  3. Divide each result by the sum.
Notes: The sum of the probabilities is 1. A chat AI uses the same function for the next token. The temperature divides the scores before softmax. A low temperature makes the largest probability larger. Refer to Module 5, Section 5 . During training, the loss measures how much probability the model gave to the correct answer. A frequent loss is cross-entropy : loss = −log(probability of the correct answer). Thus the model gets a large loss when it is sure but wrong. Training makes this loss smaller. Open the section

Vectors

A vector is an ordered list of numbers. One example in the data is a vector of its features. For example, a mango with a weight of 300 g, a length of 12 cm, and a ripeness score of 0.8 is the vector [300, 12, 0.8]. An embedding is also a vector. Refer to Module 4, Section 7.

  • Add two vectors: add the numbers in the same position. [1, 2] + [3, 1] = [4, 3].
  • Multiply a vector by a number: multiply each number. 2 × [1, 2] = [2, 4].
  • The length of a vector: √(sum of the squares). The length of [3, 4] is √(9 + 16) = 5.
Notes: The dot product multiplies the numbers in the same positions, and then adds the results: Example: [1, 2] · [3, 1] = 1 × 3 + 2 × 1 = 5. A neuron calculates a dot product: its inputs · its weights. Refer to Module 4, Section 3 . Cosine similarity measures if two vectors point in the same direction. Matrices

A matrix is a table of numbers, with rows and columns. A data set is a matrix: each row is one example, and each column is one feature. A matrix with 6,000 rows and 3 columns has the shape 6,000 × 3.

Notes: To multiply a matrix by a vector, calculate the dot product of each row with the vector. Each row gives one number. Refer to Figure 4. A layer of a neural network does exactly this calculation. Each row of the matrix contains the weights of one neuron. Then the layer adds the biases and applies the activation function: A large model does billions of these multiplications for each answer. GPUs can do many of them at the same time. This is why AI uses GPUs. Open the section

Calculus: rates of change

The slope of a straight line shows how much the output changes when the input increases by 1. For f(x) = 2x + 1, the slope is 2.

  • At x = 3, the slope is 6. The curve goes up quickly.
  • At x = −1, the slope is −2. The curve goes down.
  • At x = 0, the slope is 0. This is the bottom of the curve.
Notes: A curve does not have one slope. Its slope changes at each point. The derivative is the slope of the curve at one point. For f ( x ) = x ², the derivative is f ′( x ) = 2 x : Gradient descent uses this information. If the slope of the loss is positive, a smaller weight decreases the loss. If the slope is negative, a larger weight decreases the loss. Thus each step moves the weight in the direction opposite to the slope: Refer to Module 3, Section 8 . Open the section

Summary

  • A model is a function with parameters. Training finds good values for the parameters.
  • The mean, the median, and the standard deviation describe data. Look for outliers.
  • Many measurements have a normal distribution. Standardization gives features a similar size.
  • Correlation shows that two values change together. It does not show cause.
  • Bayes' rule changes a probability with new information. Rare events give many false alarms.
  • Softmax changes scores into probabilities. Cross-entropy measures the loss.
