What AI is

AI is a type of computer software. It does tasks that usually need a human mind.

Notes: Examples of these tasks are: A usual computer program obeys rules. A person writes these rules, one by one. An AI system is different. It finds its own rules. It finds these rules in a large quantity of examples. We call these examples data . Open the section

How a chat AI makes text

A chat AI uses a large language model (LLM). An LLM is trained on a very large quantity of text. This text comes from books, websites, and code.

Notes: An LLM does one main task. It predicts the next word in a text. It does this task again and again. This makes full sentences and full answers. An LLM does not look up facts in a database. It makes text that is probable, from the patterns that it learned. This is very useful. But it is also the cause of some errors. Refer to Section 8. Most LLMs use a design that has the name transformer . A transformer uses a method with the name attention . Attention lets each word "look at" the other words in the text. Thus the model knows that "bank" in "river bank" is different from "bank" in "bank account". Open the section

Limits and risks

An AI system can give incorrect information that looks correct. Do not use AI output for medical, legal, financial, or safety decisions without a check by a qualified person.

  • Incorrect answers. An LLM can make facts, names, or references that do not exist. We call this a hallucination.
  • Bias. A model learns from data that people made. If the data is not fair, the model can also be not fair.
  • Old information. A model knows only the data from before its training stopped. Some systems can search the web to get new information.
  • No real understanding. A model finds patterns. It does not have human experience of the world.
Notes: Know these limits of AI: Do not give private data to an AI tool if you do not know how the tool keeps that data. Private data includes passwords, ID numbers, and company secrets. Open the section

A short history of AI

AI is not new. Researchers started to work on it in the 1950s. There were periods of large hopes and periods of disappointment. The large changes came when three things became available together: large quantities of data, fast computer chips, and better methods.

Notes: In his paper “Computing Machinery and Intelligence”, Turing describes a test. Can a person find the difference between a computer and a human in a written conversation? At a workshop at Dartmouth College in the USA, researchers use the name “artificial intelligence” for the new subject. John McCarthy suggested the name. Frank Rosenblatt makes the perceptron, one of the first machines that learns from examples. It is a very simple neural network. Open the section

Summary

  • AI is software that does tasks that usually need a human mind.
  • Machine learning finds rules in data. A person does not write the rules.
  • Training is a loop: guess, compare, adjust, repeat.
  • A neural network has layers of neurons. Weights connect the neurons.
  • A chat AI predicts the next token again and again.
  • AI can make errors. Always do a check of important information.
