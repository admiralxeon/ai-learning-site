What deep learning is

Deep learning is a part of machine learning. It uses neural networks with many layers. The word "deep" refers to the number of layers. A deep network can have from ten to more than one hundred layers.

Notes: In classic machine learning, a person usually selects the features. For example, to identify a cat, a person can tell the model to measure the shape of the ears. In deep learning, the network finds the useful features in the raw data. Refer to Figure 1. Deep learning is the best method for data that does not have a clear structure, for example images, sound, and text. For data in tables, classic methods are frequently as accurate as deep learning. How a deep network learns

A deep network learns with gradient descent. Refer to Module 3, Section 8. But a deep network has millions or billions of weights. The system must find the gradient for each weight. A method with the name backpropagation does this quickly. Refer to Figure 3.

Notes: The system does not use all the training data at one time. It uses small groups of examples. We call each group a batch . One pass through all of the training data is an epoch . Training usually needs many epochs. Open the section

How a network finds patterns in images

A photograph has millions of pixels. A usual network would need too many weights. A convolutional neural network (CNN) solves this problem.

Notes: A CNN uses small filters . A filter is a small grid of weights, for example 3 × 3. The filter moves across the image, one position at a time. At each position, it calculates one number. The result is a new grid that we call a feature map . The feature map shows where the filter found its pattern. Refer to Figure 4. The same filter is used at all positions. How a transformer uses attention

Module 1 tells you that most LLMs use a transformer. This section tells you how a transformer works.

Notes: The meaning of a word depends on the other words in the text. Look at the sentence "The animal did not cross the street because it was tired". Here, the word "it" refers to the animal. In "... because it was too wide", the word "it" refers to the street. A method with the name attention solves this problem. For each token, attention calculates how important each other token is. Then it adds information from the important tokens into this token. Refer to Figure 6. A transformer does the calculations for all tokens at the same time. Thus it can use the power of GPUs well. Deep learning in practice

Deep learning needs very many calculations. A GPU is a computer chip that does many calculations at the same time. Small networks can train on one GPU. Large language models train on thousands of GPUs for weeks or months.

  • Dropout. During training, the system switches off some random neurons. Thus the network cannot depend on a small number of neurons.
  • Data augmentation. The system makes more training examples from the existing examples. For example, it turns, flips, or crops each image.
  • Early stopping. The system stops training when the validation loss starts to increase.
Notes: A deep network has very many weights. Thus it can easily remember the training data. Refer to Module 3, Section 9 . Use these methods to prevent overfitting: To train a large network from zero, you need very much data and money. Transfer learning is a different method: The network keeps its general knowledge, for example how to find edges and shapes. It only learns the new task. Generative AI uses the same principle. Summary

  • Deep learning uses neural networks with many layers. The network finds the features in the raw data.
  • Each neuron multiplies its inputs by weights, adds a bias, and applies an activation function.
  • Backpropagation finds the gradient for each weight. Gradient descent then adjusts the weights.
  • CNNs use filters to find patterns in images.
  • Embeddings change items into lists of numbers. Similar items have similar embeddings.
  • Transformers use attention to connect each token to the other tokens.
