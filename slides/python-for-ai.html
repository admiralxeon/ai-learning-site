Python and data tools

After this module, you can:

  • Run Python in Google Colab and on your own computer.
  • Write code with lists, dictionaries, loops, conditions, and functions.
  • Load, clean, filter, and summarize a table of data with pandas.
  • Get data from a database with SQL.
  • Use the terminal, a virtual environment, and Git.

Set up your tools

Python is the main language of AI. Most AI libraries, for example scikit-learn and PyTorch, use it. You can run Python in two ways.

  1. Install Python 3 from python.org. On Windows, select Add python.exe to PATH during the installation.
  2. Install a code editor, for example VS Code, and its Python extension.
  3. Make a folder for your project. Open a terminal in that folder. Refer to Section 8.
  4. Make a virtual environment and install the libraries with the commands below.
Notes: Colab is a notebook : a page with cells. Each cell contains code. When you run a cell, the output shows below it. To start, open Google Colab and select New notebook . A virtual environment keeps the libraries of each project separate. pip installs libraries. The last command saves the exact versions in requirements.txt . Refer to Module 8, Section 6 . NumPy: calculate with arrays

A Python list is slow for large calculations. NumPy keeps numbers in an array, and does one operation on all of them at the same time. An array with one row is a vector. An array with rows and columns is a matrix. Refer to Module 2, Section 9.

  • weights / 1000 divides each value. You do not need a loop.
  • weights[weights > 250] selects the values that agree with a condition.
  • X.shape is (5, 3): 5 rows (mangoes) and 3 columns (features). This is the usual shape of ML data. Refer to Module 3, Section 4.
  • axis=0 calculates down each column. axis=1 calculates along each row.

pandas: work with tables

pandas works with tables. A table in pandas is a DataFrame. Each column has a name. With pandas, you can load a CSV file, find missing values, filter rows, and make summaries.

Notes: A CSV file is a text file. Each line is a row. Commas separate the values. Most data sets come as CSV files. Open the section

SQL: get data from a database

Companies keep most of their data in databases, not in CSV files. SQL is the language to ask a database for data. A query tells the database which rows and columns you want. Python has a small database, SQLite, so you can practice without a server.

Read errors and repair code

All programmers get errors every day. An error message is help, not a failure. Read it from the bottom: the last line gives the type of error and the cause.

  1. Read the last line of the error. Find the type and the message.
  2. Find the line number in the message. Look at that line and the line before it.
  3. Print the values just before the error, for example print(type(w), w).
  4. Make one change, and run the code again.
  5. If you ask a chat AI for help, give it the full error and the code. Then make sure that you understand the solution before you use it. Refer to Module 5, Section 9.

Good habits

  • Use clear names. weight_g is better than w2. Other people, and you after one month, must understand the code.
  • Make small functions. Each function does one task. Small functions are easy to test.
  • Write a comment for why, not for what. The code shows what it does. A comment tells why.
  • Run often. Write a few lines, run them, and look at the output. Do not write 100 lines before the first test.
  • Keep the data separate. Do not change the original data file. Save a cleaned copy with a new name.
  • Use Git from the first day. Commit each time that something works.
