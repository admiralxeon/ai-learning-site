AI learning manual

This manual teaches artificial intelligence in short modules. Each module is written in ASD-STE100 Simplified Technical English, at approximately 80% compliance. Each module has diagrams and explainer videos.

1

How to use this manual

  1. Start with Module 1. It gives the basic words and ideas.
  2. Read the modules in sequence. Each module uses the words from the modules before it.
  3. Look at each figure when the text tells you to.
  4. Watch the videos after you read the text. The videos give more detail.
  5. Put the pointer on a name with a dotted line to see its definition.
  6. At the end of each module, do the knowledge check.

About the writing standard

ASD-STE100 is a controlled language. Aerospace companies use it for maintenance manuals. Its rules make text clear for all readers. This includes readers who do not speak English as their first language.

Some of the rules are:

  • Write short sentences. A procedure sentence has a maximum of 20 words.
  • Use the active voice.
  • Use one word for one meaning.
  • Write one instruction in each sentence.
Note

This manual uses some technical names that are not in the STE dictionary. Each module has a list of these names at the end.
