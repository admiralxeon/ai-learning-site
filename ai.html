Artificial intelligence: general description

This document is written in ASD-STE100 Simplified Technical English. Approximately 80% of the text obeys the STE rules. Some technical names are not in the STE dictionary. These names have a dotted line. Put the pointer on a name to see a short definition.

1

Scope

This document gives a general description of artificial intelligence (AI).

It tells you:

  • What AI is.
  • How AI is different from a usual computer program.
  • How an AI system learns.
  • How a chat AI makes text.
  • The limits and risks of AI.

You do not need special knowledge to read this document.

2

What AI is

AI is a type of computer software. It does tasks that usually need a human mind.

Examples of these tasks are:

  • To identify a face in a photograph.
  • To translate text from one language to a different language.
  • To change speech into written text.
  • To answer a question in a chat.
  • To find a defect on a part from a camera image.

A usual computer program obeys rules. A person writes these rules, one by one. An AI system is different. It finds its own rules. It finds these rules in a large quantity of examples. We call these examples data.

🥭
Project: the mango checker · Part 1 of 7

Rules or learning?

Asha has a mango farm near Ratnagiri. Each day, her workers sort thousands of mangoes into three boxes: ripe, not ripe, and damaged. This work is slow, and tired workers make errors.

Asha's nephew writes a usual computer program. It obeys one rule: "If the skin is yellow, the mango is ripe." The rule does not work well:

  • Some types of ripe mango stay green.
  • In the evening light, green mangoes look yellow.
  • The rule cannot find small black spots of damage.

Thus Asha decides to use AI. A model will learn the rules from many photographs that experienced workers sort.

Think: why is it difficult to write rules for this task?

Ripeness depends on many small signs together: the color, small spots, the shape, and the light in the photograph. A person cannot write a rule for each combination. A model can find these patterns in many examples.

3

The parts of AI

AI is a large area. It has smaller areas in it. Refer to Figure 2.

  • Artificial intelligence is the full area. It includes all methods that make a computer do "smart" tasks.
  • Machine learning (ML) is one part of AI. The computer learns from data.
  • Deep learning is one part of ML. It uses a large neural network.
  • Generative AI is one part of deep learning. It makes new text, images, sound, or code. A chat AI is an example.

Each of these areas has its own module. Module 2 gives the mathematics that they use. Refer to Module 3, Machine learning, Module 4, Deep learning, and Module 5, Generative AI.

Note

All AI systems that you can use today are "narrow" AI. Each system can do only some types of tasks. A system that can do all human tasks does not exist at this time. We call that type of system AGI.

4

How an AI system learns

The learning procedure is training. The result of training is a model. The model keeps what it learned as a very large set of numbers. We call these numbers weights.

Training is a loop. The loop has these steps. Refer to Figure 3.

  1. The model receives an example from the data.
  2. The model makes a guess.
  3. The system compares the guess with the correct answer.
  4. The system calculates the error. The error shows how far the guess is from the correct answer.
  5. The system adjusts the weights by a small quantity. This makes the next error smaller.
  6. The loop starts again with the next example.

The loop can occur millions or billions of times. After many loops, the guesses become accurate.

For more information about training, refer to Module 3, Machine learning.

Three types of learning

TypeWhat the system getsExample
Supervised learningData with the correct answers.Emails with the label "spam" or "not spam".
Unsupervised learningData with no answers. The system finds groups and patterns.Put customers into groups that buy the same products.
Reinforcement learningA reward for a good action and a penalty for a bad action.A program learns to play a game. It gets points when it wins.
5

Neural networks

Most modern AI uses a neural network. A neural network has many small units. We call these units neurons. The neurons are in layers. Refer to Figure 4.

  • The input layer receives the data. For a photograph, each neuron receives the value of one pixel.
  • The hidden layers do the calculations. The first layers find simple shapes, for example edges. The subsequent layers find larger shapes, for example eyes or ears.
  • The output layer gives the result. For example: "cat: 92%".

Each line between two neurons has a weight. A large weight makes the connection strong. A small weight makes it weak. Training adjusts all these weights.

For more information about how a neural network calculates and learns, refer to Module 4, Deep learning.

How a chat AI makes text

A chat AI uses a large language model (LLM). An LLM is trained on a very large quantity of text. This text comes from books, websites, and code.

An LLM does one main task. It predicts the next word in a text. It does this task again and again. This makes full sentences and full answers.

The procedure

  1. You write a question. We call this the prompt.
  2. The system cuts the text into small parts. We call these parts tokens.
  3. The model calculates a probability for each possible next token.
  4. The system selects one token. Usually it selects a token with a high probability.
  5. The system adds the token to the text.
  6. The system goes back to step 3. It stops at the end of the answer.
Try it

Cut text into tokens

Write a sentence in the box. Look at how the system cuts it into tokens. Then try the examples below. Look at long words and numbers.

An LLM does not look up facts in a database. It makes text that is probable, from the patterns that it learned. This is very useful. But it is also the cause of some errors. Refer to Section 8.

The transformer

Most LLMs use a design that has the name transformer. A transformer uses a method with the name attention. Attention lets each word "look at" the other words in the text. Thus the model knows that "bank" in "river bank" is different from "bank" in "bank account".

For more information about transformers, refer to Module 4, Section 8. For more information about chat AI, refer to Module 5, Generative AI.

8

Limits and risks

Warning

An AI system can give incorrect information that looks correct. Do not use AI output for medical, legal, financial, or safety decisions without a check by a qualified person.

Know these limits of AI:

  • Incorrect answers. An LLM can make facts, names, or references that do not exist. We call this a hallucination.
  • Bias. A model learns from data that people made. If the data is not fair, the model can also be not fair.
  • Old information. A model knows only the data from before its training stopped. Some systems can search the web to get new information.
  • No real understanding. A model finds patterns. It does not have human experience of the world.
Caution

Do not give private data to an AI tool if you do not know how the tool keeps that data. Private data includes passwords, ID numbers, and company secrets.

Procedure: use a chat AI safely

  1. Write a clear prompt. Tell the AI the task, the context, and the format of the answer.
  2. Read the answer carefully.
  3. Do a check of all important facts in a reliable source.
  4. If the answer is not correct, tell the AI the error and ask again.
  5. Make the final decision yourself.
9

A short history of AI

AI is not new. Researchers started to work on it in the 1950s. There were periods of large hopes and periods of disappointment. The large changes came when three things became available together: large quantities of data, fast computer chips, and better methods.

  • 1950–1969: the start
  • 1970–1993: hopes and winters
  • 1994–2011: learning from data
  • 2012–2019: deep learning
  • 2020 to now: generative AI
  1. 1950
    Alan Turing asks: can machines think?

    In his paper “Computing Machinery and Intelligence”, Turing describes a test. Can a person find the difference between a computer and a human in a written conversation?

  2. 1956
    The name “artificial intelligence”

    At a workshop at Dartmouth College in the USA, researchers use the name “artificial intelligence” for the new subject. John McCarthy suggested the name.

  3. 1958
    The perceptron

    Frank Rosenblatt makes the perceptron, one of the first machines that learns from examples. It is a very simple neural network.

  4. 1966
    ELIZA, an early chatbot

    Joseph Weizenbaum makes ELIZA. It uses simple rules to answer like a therapist. Many users think that it understands them, but it does not.

  5. 1974
    The first “AI winter”

    The results are smaller than the promises. Governments give less money for AI research. We call this period an “AI winter”.

  6. 1980s
    Expert systems

    Companies use expert systems: programs with thousands of rules that people write. The rules are expensive to keep up to date. A second AI winter starts at the end of the 1980s.

  7. 1986
    Backpropagation

    David Rumelhart, Geoffrey Hinton, and Ronald Williams show how backpropagation trains neural networks with many layers. Refer to Module 4.

  8. 1997
    A computer wins at chess

    IBM’s Deep Blue wins a chess match against the world champion, Garry Kasparov.

  9. 2009
    ImageNet

    Researchers publish ImageNet, a data set with millions of labeled photographs. Large data sets make deep learning possible.

  10. 2012
    Deep learning starts to win

    A deep CNN wins the ImageNet image competition with far fewer errors than the other methods. It trains on GPUs.

  11. 2016
    AlphaGo

    DeepMind’s AlphaGo wins against Lee Sedol, one of the best players of the game Go. It uses deep learning and reinforcement learning.

  12. 2017
    The transformer

    Google researchers publish “Attention Is All You Need”. The transformer becomes the base of most LLMs.

  13. 2020
    GPT-3

    OpenAI shows GPT-3, an LLM with 175 billion weights. It can do many tasks from a short prompt.

  14. 2022
    ChatGPT and image generators

    Diffusion image generators become available to the public. In November, ChatGPT is released. It gets approximately 100 million users in two months.

  15. 2024
    Laws for AI

    The European Union adopts the EU AI Act, the first large law about AI. Refer to Module 6.

  16. 2025
    Reasoning models and agents

    Models that work through problems in steps, and AI agents that use tools, become common.

Note

Each new method in this list uses the methods before it. A chat AI in 2025 still uses neurons from 1958 and backpropagation from 1986.

10

Summary

  • AI is software that does tasks that usually need a human mind.
  • Machine learning finds rules in data. A person does not write the rules.
  • Training is a loop: guess, compare, adjust, repeat.
  • A neural network has layers of neurons. Weights connect the neurons.
  • A chat AI predicts the next token again and again.
  • AI can make errors. Always do a check of important information.

12

Technical names

These names are not in the STE dictionary. STE lets you use technical names that are necessary for the subject.

Attention
A method that lets each token use information from the other tokens.
Data
The examples that a computer uses to learn.
Hallucination
An answer that sounds correct but is false or invented.
LLM (large language model)
A very large neural network that is trained on text.
Model
The software that training makes. It contains the learned rules as numbers.
Neural network
Software with many connected units in layers.
Prompt
The text that you give to an AI system.
Token
A small part of text: a word, a part of a word, or a punctuation mark.
Training
The procedure in which a model learns from data.
Transformer
The neural network design that most LLMs use.
Weight
An adjustable number in a model. Training changes it.
