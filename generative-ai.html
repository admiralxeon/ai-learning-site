Generative AI: general description

This module is written in ASD-STE100 Simplified Technical English, at approximately 80% compliance. Read Module 1, Artificial intelligence, Module 3, Machine learning, and Module 4, Deep learning before you read this module. Names with a dotted line are technical names. Put the pointer on a name to see its definition.

1

Scope

This module gives a description of generative AI.

It tells you:

  • What generative AI is, and how it is different from predictive AI.
  • The types of content that generative AI can make.
  • How a large language model is made.
  • How a model selects its output, and how you can control it.
  • How an image generator makes a picture.
  • How to write a good prompt.
  • How to connect a model to your documents and to tools.
  • The risks of generative AI, and how to use it responsibly.
2

What generative AI is

Most models in Module 3 are predictive. A predictive model looks at an input. Then it gives a label or a number. For example, it tells you if an email is spam.

Generative AI is different. It makes new content. This content did not exist before. The model learns the patterns in its training data. Then it uses these patterns to make new examples that are similar to the data. Refer to Figure 1.

A large generative model can do many different tasks. We call this type of model a foundation model. Companies use one foundation model in many products, for example chat, writing help, code help, and search.

Note

Generative AI does not copy text or pictures from a database. It makes new output from the patterns that it learned. But sometimes the output can be very similar to an item in the training data.

3

Types of generative AI

Generative models can make different types of content. We call each type of content a modality.

OutputExamples of tasksUsual type of model
TextAnswer questions, write drafts, make summaries, and translate.Large language model (LLM)
CodeWrite, explain, and repair program code.LLM that is also trained on code
ImagesMake a picture from a text description. Change a part of a photograph.Diffusion model. Refer to Section 6.
Sound and speechChange text into speech. Make music. Make a copy of a voice.Transformer or diffusion model
VideoMake short video clips from a text or from an image.Diffusion model
3D and designMake 3D models, product designs, and game content.Diffusion model or transformer

A multimodal model can use more than one modality. For example, it can receive a photograph and a question. Then it writes an answer about the photograph.

4

How a large language model is made

A modern chat AI is made in three stages. Refer to Figure 2.

Stage 1: Pretraining

In pretraining, the model reads a very large quantity of text. Its task is to predict the next token. For more information about tokens, refer to Module 1, Section 6. Most of these models are transformers. Refer to Module 4, Section 8.

Pretraining can take months. It uses thousands of special computer chips at the same time. We call these chips GPUs. Pretraining is the most expensive stage.

The result is a base model. A base model knows much about language and about the world. But it only continues text. If you ask it a question, it can write more questions in place of an answer.

Stage 2: Fine-tuning

In fine-tuning, the model learns from a smaller set of examples. Each example has a question and a good answer. People write or check these examples. After fine-tuning, the model follows instructions. Fine-tuning is a type of transfer learning. Refer to Module 4, Section 9.

Stage 3: Human feedback

The model writes two or more answers to the same question. People select the better answer. The model learns to give the type of answer that people prefer. This method uses reinforcement learning. Refer to Module 3, Section 7. We call this method RLHF.

After these three stages, the model is an assistant. It follows instructions, and it refuses some harmful requests.

Note

A model does not learn from your conversation immediately. Its weights change only when the company trains it again. But some companies use conversations as training data. Read the privacy settings of each AI tool that you use.

5

How a model selects its output

Module 1 tells you that a model calculates a probability for each possible next token. Then the system selects one token. We call this selection sampling.

If the system always selects the token with the highest probability, the text is predictable. But the text can become repetitive. If the system sometimes selects a token with a lower probability, the text is more varied.

A setting with the name temperature controls this. Refer to Figure 3.

TemperatureEffectUse it for
Low (0 to 0.3)The answer is almost the same each time.Facts, calculations, code, and data extraction.
Medium (0.5 to 0.8)The answer changes a little each time.Usual chat and writing.
High (1.0 or more)The answer changes much each time. Errors are more probable.Ideas, poems, and stories.
Try it

Change the temperature

Move the slider and look at the probabilities. Then select Make 10 answers. Do this at a low and at a high temperature, and compare the answers.

Note

Because of sampling, the same prompt can give a different answer each time. This is usual. It is not a fault.

The context window

A model can use only a limited quantity of text at one time. We call this limit the context window. The context window includes your prompt, the documents that you give, the conversation until now, and the answer.

The size of a context window is given in tokens. In English, 1,000 tokens are approximately 750 words. If a conversation is longer than the context window, the model cannot use the earliest parts.

6

How an image generator works

Most image generators use a diffusion model. A diffusion model learns to remove noise from an image. Refer to Figure 4.

Training

  1. The system takes an image and its text description from the training data.
  2. The system adds a small quantity of random noise to the image.
  3. The model tries to predict the noise that the system added.
  4. The system compares the prediction with the real noise. Then it adjusts the weights.
  5. The system repeats these steps with more noise, millions of times.

Generation

  1. You write a prompt.
  2. The system starts with an image that is only random noise.
  3. The model removes a small quantity of noise. The prompt tells the model what to find in the noise.
  4. The system repeats step 3 many times.
  5. A clear image appears. It is a new image that matches the prompt.

Video generators use the same principle. They also keep the frames of the video consistent with each other.

7

How to write a good prompt

The quality of the answer depends on the quality of the prompt. A good prompt gives the model the information that it needs. A good prompt can have five parts. Refer to Figure 5.

These examples show how to make a weak prompt better:

Weak promptBetter prompt
Write about rainbows.Explain how a rainbow forms, for students who are 10 years old. Use 5 short steps.
Fix my code.This Python function must return the sum of a list. It gives an error when the list is empty. Find the cause and repair it. The code is below.
Summarize this.Make a summary of this report for a manager. Use 5 bullet points. Include all costs and dates.

Useful methods

  • Give examples. Show one to three examples of the result that you want. We call this few-shot prompting.
  • Ask for steps. For a problem with calculations or logic, ask the model to show its steps. Some new models do this automatically before they answer. We call them reasoning models.
  • Divide a large task. Give the model one part of the task at a time.
  • Let the model say "I do not know". Tell the model to say this when it does not have the information. This can decrease hallucinations.
  • Try again. If the answer is not good, change the prompt. Tell the model what is wrong.

Many AI products add hidden instructions before your prompt. We call these instructions the system prompt. The system prompt gives the model its role and its rules.

Try it yourself

Copy each prompt into any chat AI. Compare the answer with the description of a good answer.

Exercise 1. Give the task, the readers, and the format.

Explain how a rainbow forms, for students who are 10 years old. Use 5 short, numbered steps. Use no more than 100 words.
What a good answer looks like

The answer has exactly 5 numbered steps and fewer than 100 words. It uses simple words: sunlight goes into raindrops, the light bends, it divides into colors, and the colors come back to your eyes. Now remove the readers and the format from the prompt, and compare the two answers.

Exercise 2. Give examples (few-shot prompting).

Put each review into one category: Positive, Negative, or Mixed.
Review: The mangoes were sweet and arrived fast. Category: Positive
Review: Half of the box was damaged. Category: Negative
Review: Good taste, but very expensive. Category:
What a good answer looks like

The answer is only one word: “Mixed”. The examples showed the model the format, so it does not write a long explanation.

Exercise 3. Let the model say “I do not know”.

Use only the text below to answer. If the text does not contain the answer, write: I do not know.
Text: Asha stores ripe mangoes at 12 to 14 degrees Celsius. She does not wash them before storage.
Question: How many days can the mangoes stay in storage?
What a good answer looks like

A good answer is “I do not know”, because the text does not give the number of days. If the AI gives a number, it invented it. This is a hallucination. Refer to Section 9.

Procedure: write a good prompt

  1. Write the task in one clear sentence.
  2. Give the context. Tell the model who will read the result, and why.
  3. Give the facts or the text that the model must use.
  4. Tell the model the format, the length, and the style of the answer.
  5. If possible, give one example of a good result.
  6. Send the prompt. Read the answer carefully.
  7. If the answer is not correct, change the prompt and send it again.
8

Connect a model to documents and tools

A model knows only its training data. It does not know your company documents or the news of today. A method with the name RAG solves this problem. Refer to Figure 6.

  1. A user asks a question.
  2. The system searches your documents for text that is related to the question. The search usually uses embeddings. Thus it finds text with the same meaning, not only the same words. Refer to Module 4, Section 7.
  3. The system puts the question and the found text into one prompt.
  4. The model writes an answer from this text.
  5. The answer shows the sources. You can use them to do a check of the answer.

RAG has these advantages:

  • The answers can use new and private data.
  • You can do a check of each source.
  • There are usually fewer hallucinations.
  • It is not necessary to train the model again when the documents change.

Project: the mango checker · Part 5 of 8

A chatbot for farmers

Asha writes a guide for other farmers: when to pick mangoes, how to keep them, and how to find damage. Many farmers telephone her with questions about the guide. Asha wants a chatbot to answer these questions.

First, she tests a usual chat AI. It gives general answers. Sometimes it invents facts about storage temperatures.

Then the team uses RAG:

  • The system searches Asha's guide for the parts that are related to each question.
  • It adds these parts to the prompt.
  • The temperature setting is low, so that the answers are consistent.
  • Each answer shows the page of the guide that it uses.

Questions about pesticides and other chemicals always go to a person. An incorrect answer can cause harm.

Think: why does the chatbot show the page of the guide with each answer?

The farmer can do a check of the answer in the guide. This decreases the risk of hallucinations.

Tools and agents

Some AI systems can use tools. For example, they can search the web, do calculations, run code, or send an email. An AI agent is a system that uses an LLM to plan steps. Then it uses tools to complete a task.

Example task for an agent: "Find three hotels in Pune for less than ₹5,000 per night. Make a table of their prices and ratings."

Caution

An agent can do actions in the real world. Make sure that a person approves each important action, for example a payment, an order, or an email.

9

Risks of generative AI

Warning

Generative AI can make content that looks real but is false. This includes text, photographs, voices, and videos. Do not believe content only because it looks real.

Know these risks:

  • Hallucinations. A model can invent facts, quotes, and references. The text can sound correct and confident. Refer to Module 1, Section 8.
  • Deepfakes. A deepfake is a false image, video, or voice of a real person. Criminals use deepfakes for fraud. For example, a false voice of a family member asks for money.
  • Copyright. Models are trained on content that people made. The rules about the use of this content are different in different countries. The output can also be similar to an existing work.
  • Bias. Text and images from a model can repeat unfair ideas from the training data.
  • Prompt injection. A web page or a document can contain hidden instructions for an AI. We call this prompt injection. These instructions can make an AI agent do something that you did not ask for.
  • Private data. Data that you give to an AI tool can be kept by the company that makes the tool.
  • Too much trust. If the AI does all the work, you learn less. Use AI to help you learn, not in place of your learning.
  • Energy. Training and use of large models need much electricity and water for cooling.
Caution

Obey the rules of your school or company for the use of AI. Some rules tell you to say when AI helped you to make a document.

Procedure: before you use AI-made content

  1. Do a check of all facts, numbers, names, and references in a reliable source.
  2. Make sure that the content does not copy the work of a different person.
  3. Make sure that the content does not contain private data.
  4. Read the content as your reader will read it. Remove errors and parts that are not clear.
  5. If your rules tell you to, say that AI helped to make the content.
  6. Accept responsibility for the final content. You are responsible for it, not the AI.
10

Summary

  • Generative AI makes new content: text, images, sound, video, and code.
  • A chat AI is made in three stages: pretraining, fine-tuning, and human feedback.
  • Temperature controls how predictable or varied the output is.
  • The context window limits how much text a model can use at one time.
  • An image generator starts from noise and removes it step by step.
  • A good prompt gives the task, the context, the format, and an example.
  • RAG lets a model use your documents and show its sources.
  • AI-made content can be false. Always do a check before you use it.

12

Technical names

These names are not in the STE dictionary. STE lets you use technical names that are necessary for the subject.

AI agent
An AI system that uses an LLM to plan steps and use tools to complete a task.
Base model
A model after pretraining only. It continues text but does not follow instructions well.
Context window
The maximum quantity of text, in tokens, that a model can use at one time.
Deepfake
A false image, video, or voice of a real person, made by AI.
Diffusion model
A model that makes images when it removes noise step by step.
Embedding
A list of numbers that shows the meaning of a text.
Few-shot prompting
A prompt method that gives the model some examples of the task.
Fine-tuning
Additional training on a smaller and more specific set of data.
Foundation model
A very large general model that people adapt for many tasks.
GPU
A computer chip that does many calculations at the same time.
Modality
One type of data, for example text, image, sound, or video.
Multimodal
Able to use more than one modality.
Noise
Random values that hide the content of an image.
Pretraining
The first and largest stage of training. The model learns to predict the next token.
Prompt injection
An attack in which hidden text gives instructions to an AI system.
RAG
Retrieval-augmented generation. The system adds relevant text from documents to the prompt.
Reasoning model
A model that works through a problem in steps before it answers.
RLHF
Reinforcement learning from human feedback. The model learns the answers that people prefer.
Sampling
The selection of the next token from the calculated probabilities.
System prompt
Instructions from the maker of an AI product that the model gets before your prompt.
Temperature
A setting that controls how random the output is.
