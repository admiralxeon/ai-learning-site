Machine learning: general description

1

Scope

This module gives a description of machine learning (ML).

It tells you:

  • The steps that make an ML system.
  • The types of data that ML uses.
  • The three types of learning.
  • How a model finds its errors and makes them smaller.
  • How to measure the quality of a model.
  • Some common ML methods.
2

What machine learning is

Machine learning is one part of AI. In ML, a computer learns from examples. A person does not write the rules. The computer finds the rules in the data.

Think of a person who learns to identify ripe mangoes. Nobody gives that person a list of rules. The person looks at many mangoes. Each time, somebody tells the person "ripe" or "not ripe". After many examples, the person can identify a ripe mango alone. ML uses the same principle.

3

The machine learning workflow

A team does these steps to make an ML system. Refer to Figure 1.

  1. Define the problem. Write what the system must predict.
  2. Collect data. Get many examples of the problem.
  3. Prepare the data. Remove errors and examples that occur two times.
  4. Divide the data into three sets. Refer to Section 4.
  5. Select a type of model.
  6. Train the model with the training data.
  7. Evaluate the model with data that it did not see before.
  8. Put the model into use. Monitor its results.

If the model is not sufficiently accurate at step 7, adjust it and train it again. When new data becomes available, go back to step 2.

4

Data

Features and labels

ML data is usually a table. Each row is one example. Each column gives one item of information about the example. We call these columns features. The value that the model must predict is the label. Refer to Figure 2.

Warning

Bad data makes a bad model. If the data has errors, gaps, or bias, the model learns them. Always do a check of the data before training.

Three sets of data

Before training, divide the data into three sets. Refer to Figure 3.

  • Training set. The model learns from this set.
  • Validation set. You use this set to adjust the model during development.
  • Test set. You use this set one time, at the end. It shows the real accuracy of the model.
Caution

Do not let the model see the test set during training. If it sees the test set, the test result will be too good. It will not show the real accuracy.

Collect the data

The team does the steps of the ML workflow. Refer to Section 3.

  1. Define the problem. Put each photograph into one of three categories: ripe, not ripe, or damaged. This is classification.
  2. Collect data. A camera above the sorting table takes 6,000 photographs.
  3. Add labels. Two experienced workers examine each mango. Their decision is the label.

5

Supervised learning

In supervised learning, each example has a label. The model learns the relation between the features and the label. There are two main types. Refer to Figure 4.

  • Regression predicts a number. Example: the price of a flat.
  • Classification predicts a category. Example: "spam" or "not spam".
6

Unsupervised learning

In unsupervised learning, the examples do not have labels. The model finds patterns alone. A usual task is clustering. The model puts similar examples into groups. Refer to Figure 5.

Example: a shop has data about its customers. Nobody knows the types of customer. The model finds three groups: students, families, and office workers. Then the shop can send different offers to each group.

Try it

Watch the model find groups

Select One step again and again. Look at how the centers (×) move until they stop. Then add points, change the number of groups, or try a new random start.

7

Reinforcement learning

In reinforcement learning, an agent learns by trial and error. The agent is in an environment. Refer to Figure 6.

  1. The agent sees the current condition of the environment. We call this the state.
  2. The agent does an action.
  3. The environment changes.
  4. The agent gets a reward. A good action gives a high reward. A bad action gives a low reward.
  5. The agent changes its behavior to get more reward in the future.

Robots, game programs, and some parts of chat AI training use this method.

8

How a model makes its errors smaller

The loss

During training, the system measures the errors of the model. The result is one number. We call this number the loss. A high loss shows many errors. A low loss shows few errors. The objective of training is to make the loss as low as possible.

Gradient descent

Most models use a method with the name gradient descent. Think of a person on a hill in fog. The person cannot see the bottom. But the person can feel the slope under the feet. The person takes a step downhill. Then the person feels the slope again and takes the next step. Gradient descent does the same thing with the loss. Refer to Figure 7.

  1. Calculate the loss for the current weights.
  2. Calculate the slope of the loss. This slope is the gradient.
  3. Move the weights a small step in the downhill direction.
  4. Do steps 1 to 3 again until the loss stops decreasing.

The size of each step is the learning rate.

Neural networks also use gradient descent. They use a method with the name backpropagation to calculate the gradient. Refer to Module 4, Section 4.

Try it

Find the bottom of the loss

Set the learning rate and the start weight. Then select One step or Run 15 steps. Try each learning rate below and look at what the steps do.

Caution

Select the learning rate carefully. If it is too large, the model jumps over the bottom and does not become accurate. If it is too small, training is very slow.

9

Overfitting and underfitting

A good model works correctly on new data. It does not only remember the training data. Refer to Figure 8.

  • Underfitting. The model is too simple. It does not find the pattern. It makes errors on the training data and on new data.
  • Good fit. The model finds the general pattern. It works correctly on new data.
  • Overfitting. The model is too complex. It remembers each training example, also the random errors. It makes many errors on new data.

Overfitting is like a student who memorizes the answers to old exam papers. That student cannot answer a new question.

To prevent overfitting:

  • Use more training data.
  • Use a simpler model.
  • Stop training when the validation loss starts to increase.

How to measure a model

After training, measure the model with the test set. For a classification model, use a confusion matrix. It compares the predictions with the correct answers. Refer to Figure 9.

MeasurementQuestion that it answersWhen it is important
AccuracyHow many of all predictions are correct?When the categories have approximately the same size.
PrecisionWhen the model says "spam", how frequently is it correct?When a false alarm is expensive. Example: a good email goes to the spam folder.
RecallOf all the real spam, how much does the model find?When a missed item is dangerous. Example: a test for a disease.
Note

High accuracy is not always good. Think of a disease that occurs in 1 of 100 persons. A model that always says "no disease" is 99% accurate. But it finds zero sick persons. Thus, also look at precision and recall.

🥭
Project: the mango checker · Part 3 of 9

Test the model

The first model is 97% accurate on the test set. Asha is happy. But her customers complain about damaged mangoes in their boxes.

The team looks at the confusion matrix. Only 3% of the mangoes are damaged, and the model finds very few of them. The recall for damaged mangoes is only 40%.

A damaged mango in a box is expensive: the customer sends back the full box. Thus the recall for damaged mangoes is the most important measurement.

The team collects more photographs of damaged mangoes and trains the model again. Now the recall for damaged mangoes is 92%.

Think: why was 97% accuracy not a good measurement for this model?

Most mangoes are not damaged. A model can be very accurate and still miss most of the damaged mangoes. Refer to the note above.

Common machine learning methods

There are many types of ML model. Each type is good for some tasks. This table shows some common types.

MethodTypeHow it worksExample use
Linear regressionSupervised, regressionFinds the straight line that is nearest to the data points.Predict the price of a flat.
Logistic regressionSupervised, classificationCalculates the probability that an example is in a category.Predict if a customer will stop a subscription.
Decision treeSupervised, bothAsks a sequence of yes/no questions about the features.Approve or refuse a loan application.
Random forestSupervised, bothUses many decision trees. Each tree gives a vote.Find fraud in card payments.
k-nearest neighborsSupervised, bothLooks at the most similar examples in the training data.Recommend similar products.
k-meansUnsupervised, clusteringPuts the data into k groups around k center points.Put customers into groups.
Neural networkAll typesMany layers of connected neurons. Refer to Module 4, Deep learning.Images, speech, text, and chat AI.

Summary

  • In ML, the computer finds the rules in data.
  • The ML workflow has eight steps, from the problem definition to monitoring.
  • Features are the inputs. The label is the correct answer.
  • Divide the data into training, validation, and test sets.
  • Supervised learning uses labels. Unsupervised learning finds groups. Reinforcement learning uses rewards.
  • Gradient descent makes the loss smaller, step by step.
  • A good model works on new data. Prevent overfitting.
  • Measure a model with accuracy, precision, and recall.

14

Technical names

These names are not in the STE dictionary. STE lets you use technical names that are necessary for the subject.

Accuracy
The percentage of all predictions that are correct.
Agent
The program that learns and makes decisions in reinforcement learning.
Classification
Supervised learning that predicts a category.
Clustering
A task that puts similar examples into the same group.
Confusion matrix
A table that compares the predictions with the correct answers.
Feature
An input value that the model uses to make a prediction.
Gradient
The slope of the loss.
Gradient descent
A method that adjusts the weights step by step to decrease the loss.
Label
The correct answer for an example.
Learning rate
A setting that controls the size of each step in gradient descent.
Loss
A number that shows how wrong the model is.
Overfitting
The model remembers the training data and does not work well on new data.
Precision
Of all positive predictions, the percentage that is correct.
Recall
Of all real positive examples, the percentage that the model finds.
Regression
Supervised learning that predicts a number.
Reward
A number that tells an agent if an action was good or bad.
Underfitting
The model is too simple to find the pattern in the data.
