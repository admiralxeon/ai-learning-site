Python and data tools for AI

This module is written in ASD-STE100 Simplified Technical English, at approximately 80% compliance. It is the first module of the AI Engineer track. It teaches the programming tools that the projects and the engineering modules use: Python, NumPy, pandas, SQL, the terminal, and Git. You do not need to know programming before you start. If you want to learn about AI without code, you can start with Module 1. Names with a dotted line are technical names. Put the pointer on a name to see its definition.

After this module, you can:
  • Run Python in Google Colab and on your own computer.
  • Write code with lists, dictionaries, loops, conditions, and functions.
  • Load, clean, filter, and summarize a table of data with pandas.
  • Get data from a database with SQL.
  • Use the terminal, a virtual environment, and Git.
Before you start

Nothing. You can start here.

Python basics

A program is a list of instructions. Python does them in order, from the top to the bottom. This example shows the most important parts of the language.

Python
# Variables and types
name = "Alphonso"          # text (str)
weight = 262.5             # a number with a decimal point (float)
boxes = 12                 # a whole number (int)
is_ripe = True             # yes or no (bool)

# A list keeps items in order. A dictionary keeps pairs of a key and a value.
weights = [262.5, 240.0, 255.5, 310.0, 198.5]
mango = {"name": name, "weight": weight, "ripe": is_ripe}

# A loop and a condition
for w in weights:
    if w >= 250:
        print(w, "large")
    else:
        print(w, "small")


# A function: a named block of code that you can use again
def mean(values):
    return sum(values) / len(values)


print("Mean weight:", mean(weights))
print(mango["name"], "weighs", mango["weight"], "g")
Output
262.5 large
240.0 small
255.5 large
310.0 large
198.5 small
Mean weight: 253.3
Alphonso weighs 262.5 g
PartWhat it does
VariableGives a name to a value: weight = 262.5.
TypesText (str), whole numbers (int), decimal numbers (float), yes or no (bool).
ListItems in order: [262.5, 240.0]. The first item is weights[0].
DictionaryPairs of a key and a value: mango["name"].
for loopDoes the indented lines one time for each item.
if and elseDoes different lines when a condition is true or false.
FunctionA named block of code that you can use again: def mean(values):
Caution

Indentation is part of Python. The lines inside a loop, a condition, or a function must start with 4 spaces. If the spaces are wrong, Python gives an IndentationError.

NumPy: calculate with arrays

A Python list is slow for large calculations. NumPy keeps numbers in an array, and does one operation on all of them at the same time. An array with one row is a vector. An array with rows and columns is a matrix. Refer to Module 2, Section 9.

Python
import numpy as np

weights = np.array([262.5, 240.0, 255.5, 310.0, 198.5])
print(weights.mean(), weights.max())
print(weights / 1000)            # the operation applies to each value: grams to kilograms
print(weights[weights > 250])    # select the values that agree with a condition

# A 2D array (a matrix): 5 mangoes, 3 features each (weight, firmness, spots)
X = np.array([[262.5, 7.1, 0],
              [240.0, 2.0, 6],
              [255.5, 6.4, 1],
              [310.0, 5.9, 2],
              [198.5, 8.0, 0]])
print(X.shape)                   # (rows, columns)
print(X.mean(axis=0))            # the mean of each column
Output
253.3 310.0
[0.2625 0.24   0.2555 0.31   0.1985]
[262.5 255.5 310. ]
(5, 3)
[253.3    5.88   1.8 ]
  • weights / 1000 divides each value. You do not need a loop.
  • weights[weights > 250] selects the values that agree with a condition.
  • X.shape is (5, 3): 5 rows (mangoes) and 3 columns (features). This is the usual shape of ML data. Refer to Module 3, Section 4.
  • axis=0 calculates down each column. axis=1 calculates along each row.

pandas: work with tables

pandas works with tables. A table in pandas is a DataFrame. Each column has a name. With pandas, you can load a CSV file, find missing values, filter rows, and make summaries.

Python
import io
import pandas as pd

csv = """farm,variety,weight_g,firmness,spots,damaged
Ratnagiri,Alphonso,262.5,7.1,0,0
Ratnagiri,Alphonso,240.0,2.0,6,1
Junagadh,Kesar,255.5,6.4,1,0
Junagadh,Kesar,,5.9,2,0
Chittoor,Totapuri,310.0,5.9,5,1
Chittoor,Totapuri,198.5,8.0,0,0
"""
df = pd.read_csv(io.StringIO(csv))     # with a file: pd.read_csv("mangoes.csv")
print(df.shape)                        # (rows, columns)
print(df.isna().sum())                 # the number of missing values in each column

# Put the median in the empty place (imputation, Module 7)
df["weight_g"] = df["weight_g"].fillna(df["weight_g"].median())

print(df[df["damaged"] == 1])          # only the rows of damaged mangoes
print(df.groupby("variety")["weight_g"].mean())
df["weight_kg"] = df["weight_g"] / 1000   # make a new column
print(df.head())

SQL: get data from a database

Companies keep most of their data in databases, not in CSV files. SQL is the language to ask a database for data. A query tells the database which rows and columns you want. Python has a small database, SQLite, so you can practice without a server.

Python and SQL
import sqlite3

con = sqlite3.connect(":memory:")       # a small database in the memory of the computer
con.executescript("""
CREATE TABLE farms (id INTEGER PRIMARY KEY, name TEXT, state TEXT);
CREATE TABLE boxes (id INTEGER PRIMARY KEY, farm_id INTEGER, variety TEXT,
                    mangoes INTEGER, damaged INTEGER);
INSERT INTO farms VALUES (1, 'Ratnagiri', 'Maharashtra'), (2, 'Junagadh', 'Gujarat');
INSERT INTO boxes VALUES (1, 1, 'Alphonso', 24, 1), (2, 1, 'Alphonso', 24, 0),
                         (3, 2, 'Kesar', 30, 3), (4, 2, 'Kesar', 30, 1);
""")

query = """
SELECT farms.name, SUM(boxes.mangoes) AS mangoes, SUM(boxes.damaged) AS damaged
FROM boxes
JOIN farms ON farms.id = boxes.farm_id
GROUP BY farms.name
ORDER BY damaged DESC;
"""
for row in con.execute(query):
    print(row)
Output
('Junagadh', 60, 4)
('Ratnagiri', 48, 1)
SQL wordWhat it does
SELECTThe columns that you want.
FROMThe table.
WHEREA condition for the rows, for example WHERE damaged > 0.
JOIN … ONConnects two tables with a shared column. Here, each box has the id of its farm.
GROUP BYMakes one row for each group. Use it with SUM, COUNT, or AVG.
ORDER BYSorts the result. DESC puts the largest first.

To get the result as a DataFrame, use pd.read_sql(query, con).

Read errors and repair code

All programmers get errors every day. An error message is help, not a failure. Read it from the bottom: the last line gives the type of error and the cause.

Python
weights = [262.5, 240.0, "255.5"]      # the last value is text, not a number

try:
    print(sum(weights) / len(weights))
except TypeError as error:
    print("Error:", error)
    weights = [float(w) for w in weights]   # change each value into a number
    print(round(sum(weights) / len(weights), 1))
Output
Error: unsupported operand type(s) for +: 'float' and 'str'
252.7

try runs code that can fail. except catches the error, so the program does not stop. Here, one value was text ("255.5"), not a number. Data from files and users frequently contains problems like this.

ErrorUsual cause
SyntaxErrorA missing bracket, quote, or colon.
IndentationErrorThe spaces at the start of a line are wrong.
NameErrorA name that you did not make yet, or a spelling error.
TypeErrorAn operation with the wrong type, for example a number plus text.
KeyErrorA key or a column name that does not exist.
ModuleNotFoundErrorThe library is not installed. Use pip install.

Procedure: repair an error

  1. Read the last line of the error. Find the type and the message.
  2. Find the line number in the message. Look at that line and the line before it.
  3. Print the values just before the error, for example print(type(w), w).
  4. Make one change, and run the code again.
  5. If you ask a chat AI for help, give it the full error and the code. Then make sure that you understand the solution before you use it. Refer to Module 5, Section 9.

The terminal and Git

The terminal is a window where you type commands. Engineers use it to run programs, install libraries, and use Git. In VS Code, open it with the menu Terminal, then New Terminal.

CommandWhat it does
cd folderGo into a folder. cd .. goes up one folder.
ls (on Windows: dir)Show the files in the folder.
python train.pyRun a Python program.
pip install pandasInstall a library.
git initStart a Git repository in this folder.
git statusShow the files that changed.
git add . then git commit -m "message"Save a version of the changes, with a message.
git log --onelineShow the saved versions.
git pushSend the saved versions to GitHub.

Git keeps each version of your files. If you make an error, you can go back. Module 8 tells you how teams use Git with branches and pull requests. Refer to Module 8, Section 4.

Warning

Do not put passwords, API keys, or private data into a Git repository. Refer to Module 8, Section 10.

9

Good habits

  • Use clear names. weight_g is better than w2. Other people, and you after one month, must understand the code.
  • Make small functions. Each function does one task. Small functions are easy to test.
  • Write a comment for why, not for what. The code shows what it does. A comment tells why.
  • Run often. Write a few lines, run them, and look at the output. Do not write 100 lines before the first test.
  • Keep the data separate. Do not change the original data file. Save a cleaned copy with a new name.
  • Use Git from the first day. Commit each time that something works.

Summary

  • Use Google Colab to learn. Use Python on your computer, with a virtual environment, for real software.
  • Python has values, lists, dictionaries, loops, conditions, and functions. Indentation is part of the language.
  • NumPy calculates with whole arrays at the same time. ML data is usually a matrix: one row for each example, one column for each feature.
  • pandas loads, cleans, filters, and summarizes tables. A table is a DataFrame.
  • SQL gets data from databases with SELECT, FROM, WHERE, JOIN, GROUP BY, and ORDER BY.
  • Read an error from its last line. Change one thing at a time.
  • Use the terminal to run programs, and Git to keep versions.

Technical names

These names are not in the STE dictionary. STE lets you use technical names that are necessary for the subject.

Array
A NumPy grid of numbers of one type: a vector, a matrix, or more dimensions.
CSV
Comma-separated values: a text file in which each line is a row and commas separate the values.
DataFrame
A pandas table: rows of examples and named columns of values.
Dictionary
A Python collection of pairs of a key and a value.
Function
A named block of code that takes inputs and can give back a result.
Notebook
A document with cells of code, their outputs, and text, for example Jupyter or Colab.
NumPy
A Python library for fast calculations with arrays of numbers.
pandas
A Python library for tables of data.
Python
A programming language that is easy to read. Most AI work uses it.
Query
A request to a database for data, written in SQL.
SQL
Structured Query Language: the standard language to get and change data in a database.
Terminal
A program where you type commands to the computer.
Variable
A name that refers to a value.
Virtual environment
A separate folder of Python libraries for one project.
