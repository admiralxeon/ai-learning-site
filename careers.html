Careers and next steps

This page is written in ASD-STE100 Simplified Technical English. It tells you about the jobs that use AI, the skills that each job needs, what to learn after this course, and how to show your work to an employer. Job names and requirements change between companies and countries. Use this page as a general guide.

1

Scope

This course gives you the base of AI. A job usually needs more: practice with real tools, a portfolio of projects, and knowledge of one area of work. This page helps you to select a direction and to plan the next steps.

Note

Not all AI jobs need advanced mathematics or programming. Product, design, law, and domain jobs also use AI every day. Your knowledge of an area, for example farming, health, or finance, is valuable together with AI.

4

What to learn next

Do the steps in this order. Each step takes approximately one to three months with a few hours each week. Make one small project in each step.

  1. Programming and data. Learn Python, the pandas library for tables, and SQL for databases. Learn to use Git to keep versions of your code.
  2. Machine learning in practice. Use scikit-learn with real data sets. Practice data preparation, baselines, and cross-validation. Refer to Module 7.
  3. Deep learning. Learn PyTorch. Train a small image or text model, then use transfer learning.
  4. Applications with LLMs. Use an LLM through its API. Build a RAG system, write an evaluation set, and add guardrails. Refer to Module 9.
  5. Deployment. Put a model behind an API, in a container, with a CI/CD pipeline, and monitor it. Refer to Module 8.

5

Make a portfolio from your projects

A portfolio shows what you can do. For many employers, it is more important than a certificate. Use the nine projects of this manual as a start, and then add a project of your own.

Procedure: present a project

  1. Make a free account on GitHub. Make one repository for each project.
  2. Put the notebook or the code into the repository. Make sure that it runs from the start to the end.
  3. Write a README file with the template below.
  4. Change the project a little, so that it is your own work. For example, use a different data set, or compare two models.
  5. Add a link to the repository in your CV and in your professional profiles.
README template (Markdown)
# Spam filter for SMS messages

## The problem
Find spam messages automatically, so that people do not see them.

## The data
5,572 SMS messages with the labels "spam" and "ham" (SMS Spam Collection, UCI).
13.4% of the messages are spam.

## What I did
1. Divided the data: 80% training, 20% test, with the same share of spam in each.
2. Baseline: always predict "ham". Accuracy 86.6%, recall 0%.
3. Model: word counts and Naive Bayes.

## Results
| Model     | Accuracy | Precision | Recall |
|-----------|----------|-----------|--------|
| Baseline  | 0.866    | -         | 0.00   |
| My model  | 0.991    | 0.993     | 0.94   |

## Limits
Recall is lower for short messages (0.75) than for long messages (0.95).
The data is more than ten years old. New types of spam can be different.

## What I learned
Accuracy alone is not a good measurement when one category is rare.
Note

Employers like honest limits. A README that tells what did not work, and why, shows that you understand the model.

7

Summary

  • There are many AI jobs. Some need much programming, and some need knowledge of users, law, or one area of work.
  • Select a direction, then learn the skills of that job in steps: programming and data, ML, deep learning, LLM applications, deployment.
  • Make a portfolio. Put each project on GitHub with a clear README, a baseline, results, and honest limits.
  • Practice short, simple answers to the usual interview questions, with examples from your projects.
