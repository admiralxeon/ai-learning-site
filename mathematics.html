Mathematics for machine learning

This module is written in ASD-STE100 Simplified Technical English, at approximately 80% compliance. Read Module 1, Artificial intelligence before you read this module. This module gives the mathematics that the next modules use: statistics, probability, linear algebra, and basic calculus. You do not need to do the calculations by hand. Computers do them. But you must understand the ideas. Names with a dotted line are technical names. Put the pointer on a name to see its definition.

1

Scope

This module gives a description of the mathematics that machine learning uses.

It tells you:

  • Why AI needs mathematics, and which parts it needs.
  • How to describe data with statistics.
  • How to calculate and use probabilities.
  • How vectors and matrices keep and change data.
  • How calculus tells a model which direction makes its errors smaller.
Note

If mathematics is new for you, read each example slowly, and use the activities. You can also use the quick path on the home page. It shows only the most important sections.

2

Why AI needs mathematics

A model is a mathematical function. It changes input numbers into output numbers. Training changes the numbers inside the function until the output is good. Four parts of mathematics do this work:

3

Variables and functions

A variable is a name for a value that can change. Mathematics usually uses letters, for example x or w.

A function is a rule that changes each input into one output. Refer to Figure 1.

In the function f(x) = 2x + 1, the numbers 2 and 1 are parameters. A model is a function with many parameters. In a neural network, the parameters are the weights and the biases. Training finds good values for them.

The symbol Σ (sum)

Machine learning frequently adds many values. The symbol Σ (the Greek letter sigma) means "add all of these".

Σ xi = x1 + x2 + x3 + …

Example: for the values 2, 5, and 3, Σ xi = 2 + 5 + 3 = 10. The small i is a counter. It shows the position of each value in the list.

4

Statistics: describe data

Before you train a model, you must know your data. Statistics gives a few numbers that describe many values. In this section, the data is the weight of seven mangoes from Asha's farm, in grams:

280, 290, 295, 300, 305, 310, 315

The center of the data

  • The mean (average) is the sum of the values, divided by the number of values: 2,095 ÷ 7 ≈ 299 g.
  • The median is the middle value when the values are in order: 300 g.
  • The mode is the value that occurs most frequently. Here, each value occurs one time, so there is no mode.

The spread of the data

  • The range is the largest value minus the smallest value: 315 − 280 = 35 g.
  • The variance shows how far the values are from the mean. For each value, calculate the difference from the mean, and multiply the difference by itself. The variance is the mean of these results.
  • The standard deviation is the square root of the variance. It has the same unit as the data. Here it is approximately 11 g. Thus most mangoes weigh between 288 g and 310 g.

standard deviation = √( Σ(xi − mean)² ÷ n )

Warning

An outlier is a value that is very different from the others. One outlier can change the mean very much. If a worker types 2,000 g in place of 315 g, the mean becomes 540 g. The median stays at 300 g. Always look for outliers before you train a model.

Distributions

A distribution shows how frequently each value occurs. Many measurements in nature have a normal distribution. Its shape is like a bell. Most values are near the mean. Few values are far from the mean. Refer to Figure 2.

In a normal distribution:

  • Approximately 68% of the values are within 1 standard deviation of the mean.
  • Approximately 95% are within 2 standard deviations.
  • Approximately 99.7% are within 3 standard deviations.

Standardization

Features can have very different sizes. For example, the weight of a mango is approximately 300, but its ripeness score is between 0 and 1. Many models learn better when all features have a similar size. Standardization changes each value into a z-score:

z = (x − mean) ÷ standard deviation

Example: a mango of 322 g has z = (322 − 300) ÷ 11 = 2. It is 2 standard deviations heavier than the mean. This is unusual, but not an error.

6

Correlation

Correlation shows how strongly two values change together. The correlation coefficient r is between −1 and +1. Refer to Figure 3.

  • r near +1: when one value increases, the other also increases. Example: the length and the weight of a mango.
  • r near −1: when one value increases, the other decreases. Example: the days after picking and the firmness of a mango.
  • r near 0: there is no straight-line relation. Example: the weight of a mango and the day of the week.
Caution

Correlation does not show cause. In summer, people buy more ice cream, and more people swim and have accidents in the water. The two values have a strong correlation, but ice cream does not cause the accidents. The hot weather causes both. A model learns correlations. It does not know causes.

7

Probability

A probability is a number between 0 and 1. It shows how possible an event is. 0 means "impossible". 1 means "certain". We write P(A) for "the probability of A".

  • A usual die has 6 sides. P(you throw a 6) = 1 ÷ 6 ≈ 0.17.
  • The probability that A does not occur is 1 − P(A). P(no 6) = 1 − 0.17 = 0.83.
  • If two events do not have an effect on each other, they are independent. The probability that both occur is P(A) × P(B). Two coins both show heads: 0.5 × 0.5 = 0.25.

Conditional probability

A conditional probability is the probability of A when you know that B occurred. We write P(A | B), and we say "the probability of A, given B".

Bayes' rule

Bayes' rule changes a probability when you get new information:

P(A | B) = P(B | A) × P(A) ÷ P(B)

Example: 3% of Asha's mangoes are damaged. The checker finds 90% of the damaged mangoes. But it also puts 5% of the good mangoes into the damaged box. If a mango is in the damaged box, what is the probability that it is really damaged? Think of 1,000 mangoes:

  1. 30 mangoes are damaged. The checker finds 90% of them: 27 mangoes.
  2. 970 mangoes are good. The checker puts 5% of them in the damaged box: approximately 49 mangoes.
  3. The damaged box contains 27 + 49 = 76 mangoes. Only 27 of them are damaged.
  4. P(damaged | in the damaged box) = 27 ÷ 76 ≈ 0.36.

Thus only 36% of the mangoes in the damaged box are really damaged. This is the precision of the checker. Refer to Module 3, Section 10.

Note

When an event is rare, even a good test gives many false alarms. This is true for disease tests, fraud detection, and damaged mangoes.

Probability in AI models

From scores to probabilities: softmax

A classification model first calculates a score for each category. A function with the name softmax changes the scores into probabilities:

  1. Calculate escore for each score. The number e is approximately 2.718.
  2. Add all the results.
  3. Divide each result by the sum.
CategoryScoreescoreProbability
Ripe27.397.39 ÷ 11.11 = 0.67
Not ripe12.722.72 ÷ 11.11 = 0.24
Damaged01.001.00 ÷ 11.11 = 0.09

The sum of the probabilities is 1. A chat AI uses the same function for the next token. The temperature divides the scores before softmax. A low temperature makes the largest probability larger. Refer to Module 5, Section 5.

The loss for a probability

During training, the loss measures how much probability the model gave to the correct answer. A frequent loss is cross-entropy: loss = −log(probability of the correct answer).

  • The correct answer gets 0.9: loss = −log(0.9) ≈ 0.11. This is a small loss.
  • The correct answer gets 0.1: loss = −log(0.1) ≈ 2.30. This is a large loss.

Thus the model gets a large loss when it is sure but wrong. Training makes this loss smaller.

9

Vectors

A vector is an ordered list of numbers. One example in the data is a vector of its features. For example, a mango with a weight of 300 g, a length of 12 cm, and a ripeness score of 0.8 is the vector [300, 12, 0.8]. An embedding is also a vector. Refer to Module 4, Section 7.

Calculations with vectors

  • Add two vectors: add the numbers in the same position. [1, 2] + [3, 1] = [4, 3].
  • Multiply a vector by a number: multiply each number. 2 × [1, 2] = [2, 4].
  • The length of a vector: √(sum of the squares). The length of [3, 4] is √(9 + 16) = 5.

The dot product

The dot product multiplies the numbers in the same positions, and then adds the results:

a · b = a1b1 + a2b2 + …

Example: [1, 2] · [3, 1] = 1 × 3 + 2 × 1 = 5. A neuron calculates a dot product: its inputs · its weights. Refer to Module 4, Section 3.

Cosine similarity

Cosine similarity measures if two vectors point in the same direction. It is the dot product divided by the two lengths:

cosine similarity = (a · b) ÷ (|a| × |b|)

The result is between −1 and +1. A value near 1 means "very similar". Search systems with embeddings use this measurement to find text with the same meaning.

Matrices

A matrix is a table of numbers, with rows and columns. A data set is a matrix: each row is one example, and each column is one feature. A matrix with 6,000 rows and 3 columns has the shape 6,000 × 3.

A matrix times a vector

To multiply a matrix by a vector, calculate the dot product of each row with the vector. Each row gives one number. Refer to Figure 4.

A layer of a neural network does exactly this calculation. Each row of the matrix contains the weights of one neuron. Then the layer adds the biases and applies the activation function:

outputs = activation( W · x + b )

A large model does billions of these multiplications for each answer. GPUs can do many of them at the same time. This is why AI uses GPUs.

11

Calculus: rates of change

Slope

The slope of a straight line shows how much the output changes when the input increases by 1. For f(x) = 2x + 1, the slope is 2.

The derivative

A curve does not have one slope. Its slope changes at each point. The derivative is the slope of the curve at one point. For f(x) = x², the derivative is f′(x) = 2x:

  • At x = 3, the slope is 6. The curve goes up quickly.
  • At x = −1, the slope is −2. The curve goes down.
  • At x = 0, the slope is 0. This is the bottom of the curve.

Gradient descent uses this information. If the slope of the loss is positive, a smaller weight decreases the loss. If the slope is negative, a larger weight decreases the loss. Thus each step moves the weight in the direction opposite to the slope:

new weight = weight − learning rate × slope

Refer to Module 3, Section 8.

Try it

The gradient

A model has many weights, not one. A partial derivative is the slope for one weight, when the other weights do not change. The gradient is the vector of all the partial derivatives. It points in the direction in which the loss increases fastest. Gradient descent goes in the opposite direction.

The chain rule

In a neural network, each layer uses the output of the previous layer. The chain rule finds the slope through many steps: multiply the slopes of the steps.

if y depends on u, and u depends on x: (slope of y for x) = (slope of y for u) × (slope of u for x)

Example: three gears. Gear A turns gear B 2 times faster. Gear B turns gear C 3 times faster. Thus gear C turns 2 × 3 = 6 times faster than gear A. Backpropagation uses the chain rule from the last layer back to the first layer. Refer to Module 4, Section 4.

12

Summary

  • A model is a function with parameters. Training finds good values for the parameters.
  • The mean, the median, and the standard deviation describe data. Look for outliers.
  • Many measurements have a normal distribution. Standardization gives features a similar size.
  • Correlation shows that two values change together. It does not show cause.
  • Bayes' rule changes a probability with new information. Rare events give many false alarms.
  • Softmax changes scores into probabilities. Cross-entropy measures the loss.
  • Vectors and matrices keep data. A neural layer multiplies a matrix by a vector.
  • The derivative is the slope. Gradient descent moves opposite to the slope. The chain rule makes backpropagation possible.
